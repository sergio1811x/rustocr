# rustocr

Скоростной OCR-движок на **чистом Rust** — аналог классического пайплайна Tesseract
без единой строчки C++, системных библиотек и внешних процессов.

Движок сам бинаризует изображение, находит строки, вырезает буквы и классифицирует
их по шаблонам, отрендеренным из встроенных шрифтов. Русский + английский,
CLI и HTTP-сервер, координаты и confidence для каждого символа.

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌───────────┐   ┌──────────────┐
│ képvie   │ → │ Sauvola  │ → │ связные  │ → │ сегментация│ → │ классификация│
│ PNG/JPEG │   │ бинариза-│   │компоненты│   │ + «chop &  │   │ по шаблонам  │
│          │   │ ция      │   │ → строки │   │ associate» │   │ (8 шрифтов)  │
└──────────┘   └──────────┘   └──────────┘   └───────────┘   └──────────────┘
                     ↑ выправление перекоса (±4°) ↑    постобработка: скрипты EN/RU,
                                                           цифры/буквы, пробелы
```

## Возможности

- **Без зависимостей от системы**: шрифты встроены в бинарник (`include_bytes!`),
  декодеры PNG/JPEG/GIF/BMP — чистый Rust (крейт `image`).
- **RU + EN** в одном прогоне: латиница, кириллица, цифры, пунктуация, «№», «ё», «й».
  Неоднозначные глифы (О/О, е/е…) приводятся к доминирующему алфавиту строки.
- **Устойчив к реальности**: адаптивная бинаризация Сауволы (неравномерное освещение),
  выправление перекоса до ±4°, апскейл мелкого текста (<15 px) с восстановлением
  резкости, слияние «диакритики» (точки «ё», бревис «й»), разрезание слипшихся
  букв и слияние «ы» = «ь» + «I».
- **Полная телеметрия**: bbox и confidence каждого символа, слова и строки,
  оценка перекоса страницы, абзацные разрывы.
- **Параллелизм** на `rayon` (строки распознаются независимо).
- Скорость: **~1400 глифов/с на 2 ядрах**, линейно масштабируется по ядрам.

## Сборка

```bash
cargo build --release        # бинарник: target/release/rustocr
cargo test --release         # юнит-тесты
cargo run --release --example bench   # бенчмарк точности (см. таблицу ниже)
```

Требуется Rust 1.75+ (`rustup default stable`). Никаких системных пакетов не нужно.

## CLI

```bash
# текст в stdout
rustocr scan.png
rustocr scan.png --lang ru          # только кириллица + цифры (меньше путаниц)
rustocr scan.jpg --json > out.json  # полный JSON: строки/слова/символы с bbox и conf
rustocr scan.png --no-deskew        # не выправлять перекос
```

## HTTP-сервер

```bash
rustocr serve --port 8080 --lang both
```

| Метод | Путь     | Описание |
|-------|----------|----------|
| `POST`| `/ocr`   | тело запроса = байты изображения (PNG/JPEG/GIF/BMP), ответ — JSON. Параметр `?lang=en\|ru\|both` |
| `GET` | `/health`| статус, версия, счётчики запросов/ошибок |
| `GET` | `/`      | справка по API |

```bash
curl --data-binary @scan.png http://localhost:8080/ocr | jq -r .text
curl --data-binary @scan.jpg "http://localhost:8080/ocr?lang=ru" | jq .lines[0].words[0]
```

Формат ответа (сокращено):

```json
{
  "text": "Съешь ещё этих мягких французских булок…",
  "width": 1449, "height": 333, "skew_deg": 0.0,
  "num_glyphs": 256, "mean_conf": 0.44, "elapsed_ms": 190.3,
  "lines": [
    {
      "text": "Съешь ещё…", "conf": 0.51, "bbox": [22, 12, 1204, 55],
      "words": [ { "text": "Съешь", "conf": 0.62, "bbox": [22, 12, 105, 55] } ],
      "chars": [ { "ch": "С", "conf": 0.71, "bbox": [22, 12, 38, 55] } ]
    }
  ]
}
```

Сервер многопоточный (пул воркеров = числу ядер), движки по языкам строятся один
раз и кэшируются. Поддерживается `Expect: 100-continue` (нужно curl'у для больших
тел). Лимит тела — 64 МБ.

### systemd

```ini
[Unit]
Description=rustocr OCR server
After=network.target

[Service]
ExecStart=/usr/local/bin/rustocr serve --port 8080 --lang both
Restart=always
DynamicUser=yes

[Install]
WantedBy=multi-user.target
```

### Docker

```bash
docker build -t rustocr .
docker run -p 8080:8080 rustocr
```

## Точность (посимвольная, `cargo run --release --example bench`)

Синтетические страницы (~250 глифов, 5 строк), сравнение по Левенштейну:

| Кейс | Точность |
|---|---|
| DejaVu Sans, EN, чистый скан | **99.6%** |
| DejaVu Sans, RU («съешь ещё…») | **100.0%** |
| DejaVu Serif, RU | **100.0%** |
| DejaVu Sans Bold, EN | 95.8% |
| Liberation Sans (≈Arial), EN | 97.0% |
| FreeSans, RU / FreeSerif, EN | 98.3% / 94.1% |
| Carlito (≈Calibri), EN/RU — шрифт **не в шаблонах** | 94.5% / 88.7% |
| Моноширинный DejaVu Mono, RU — не в шаблонах | 86.8% |
| Шум σ=9 + JPEG q≈80 | **99.7%** |
| Перекос 1.5° + автовыправление | 97.0% |
| Мелкий текст 13 px (апскейл ×4) | 88.4% |
| Крупный текст 56 px | 99.2% |

Шаблонные шрифты: DejaVu Sans/Serif (+Bold), Liberation Sans/Serif, FreeSans/FreeSerif —
то есть покрываются «гейтвеи» Arial/Times/Helvetica и близкие. «Незнакомые»
человеческие шрифты читаются на 85–95%.

Скорость: страница 1449×3333 px (4200 глифов) — **~2.9 с на 2 ядрах**
(~1.4 тыс. глифов/с); типовая страница А4 в 2–3 раза меньше. Инициализация
шаблонов ~0.5–1 с (один раз при старте).

## Честные ограничения (читать перед продом)

Это **классический шаблонный движок** (по духу — Tesseract до перехода на LSTM
в 2015), а не нейросеть:

- Печатный, горизонтальный текст. **Рукописный текст не распознаётся.**
- Сильно декоративные шрифты, «рваные» сканы и текст в сценах (фото улиц) — за
  пределами возможностей; для этого нужны CRNN/PaddleOCR.
- Многоколоночные макеты и таблицы читаются построчно сверху вниз без разбора
  колонок (порядок слов может перепутаться).
- Нет словарной посткоррекции: «l/I», «о/0» в изоляции остаются на совести
  классификатора (легко добавить словарь поверх JSON-выдачи).
- Текст ниже ~10 px на глиф — на грани (апскейл спасает не всегда).

Планы развития (по возрастанию сложности): словарная коррекция слов →
поколоночный макет → обучаемая сетка-классификатор вместо шаблонов →
CRNN-строка как замена сегментации (путь Tesseract 4).

## Архитектура

| Модуль | Ответственность |
|---|---|
| `gray.rs` | интегральные изображения, бинаризация Сауволы, поворот |
| `cc.rs` | связные компоненты (union-find, 8-связность) |
| `skew.rs` | перекос: максимум дисперсии проекционного профиля |
| `layout.rs` | фильтрация блобов, строки, слияние диакритики, базовые линии |
| `segment.rs` | проекционная сегментация, «chop» (долины профиля), пробелы |
| `features.rs` | нормализация 48×48, контуры Собеля (8 направлений), Chamfer-DT, зоны, маска |
| `templates.rs` | рендер глифов из 8 встроенных TTF, набор алфавитов |
| `classify.rs` | скоринг: Chamfer×направления + зоны + аспект + XOR + базовая линия + высота |
| `ocr.rs` | оркестрация, ассоциация «ы», гармонизация скриптов, цифровой контекст |
| `server.rs` | HTTP на `std::net`: пул воркеров, `/ocr`, `/health` |
| `render.rs` | рендер текста в картинку (для тестов/бенчей) |

Признаки — идеология «микрофич» старого Tesseract: контур глифа кодируется
позициями и направлениями градиента, шаблон сравнивается с глифом через
Chamfer-преобразование по каждому из 8 направлений (устойчиво к толщине штриха
и лёгкому «раздутию» скана). Веса слагаемых подобраны координатным спуском
(`examples/tune.rs`).
